# Inventory Management Mobile App

A Flutter mobile application connected to the Inventory Management API, designed for registered users to view, track, and manage product inventory on the go.

### 🛠️ Tech Stack
- Flutter (Dart)
- REST API integration (ASP.NET Core backend)
- JWT-based authentication (via API)

### ⚙️ Key Features
- User login and secure API communication
- Product list, history, and activity tracking
- Recommender system based on collaborative filtering
- Basic profile management and search functionality

### 🚀 Notes
The app integrates with the backend API for real-time data access and inventory management features.
